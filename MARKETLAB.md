# The `marketlab` branch

This branch of the `wentbackward/ib_async` fork exists so that a project can
install `ib_async` 3.x straight from git and pin it by commit. It follows
upstream's `next-protobuf` branch and adds only:

- packaging that a git install needs (below), and
- fixes that are also offered upstream as pull requests.

No application-specific behaviour lives here.

## Distribution: the protobuf bindings are committed

Upstream generates `ib_async/_pb/` at release time from IBKR's TWS API
archive (version and SHA256 pinned in `pyproject.toml` under
`[tool.ib_async.twsapi]`) and keeps the directory out of git. A plain git
install therefore has no `_pb`, and `IB()` fails with
`ModuleNotFoundError: ib_async._pb`.

On this branch `ib_async/_pb/` is committed, generated by `make protos` from
the pinned archive with the `grpcio-tools` version locked in `uv.lock`. The
output is deterministic: two runs give byte-identical files. A consumer pins
by commit hash:

```sh
uv pip install "ib_async @ git+https://github.com/wentbackward/ib_async@<commit>"
```

or in `pyproject.toml`:

```toml
dependencies = ["ib_async @ git+https://github.com/wentbackward/ib_async@<commit>"]
```

## Moving to a newer upstream commit

```sh
git fetch upstream
git switch marketlab
git merge upstream/next-protobuf      # keep this branch's .gitignore and MARKETLAB.md
uv sync --all-groups
make protos                           # regenerate ib_async/_pb/ from the pinned archive
git add -A ib_async/_pb
git status --short ib_async/_pb       # changes only if upstream re-pinned the TWS API or grpcio-tools
uv run pytest -q                      # upstream's suite must pass
git commit -m "build: merge upstream next-protobuf <short-hash>, regenerate bindings"
git tag marketlab-<upstream-version>-<n>
git push -u origin marketlab
git push origin marketlab-<upstream-version>-<n>
```

Then check a clean install of the new commit:

```sh
uv venv /tmp/ibcheck && VIRTUAL_ENV=/tmp/ibcheck uv pip install \
  "ib_async @ git+https://github.com/wentbackward/ib_async@<commit>"
/tmp/ibcheck/bin/python -c "from ib_async import IB; IB(); print('ok')"
```

A merge conflict in `ib_async/_pb/` needs no hand resolution: take either
side, then `make protos` rewrites the directory.
